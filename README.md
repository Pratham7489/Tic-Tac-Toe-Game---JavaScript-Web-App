# 🎮✨ Tic Tac Toe Web Game – JavaScript Fun! 🕹️❌⭕️

A simple, interactive Tic Tac Toe game built with **HTML** 🌐, **CSS** 🎨, and **JavaScript** ⚡.  
Challenge a friend on your browser, track moves, get a winner or draw, and instantly replay!

---

## 🏆 Features

- 👥 Two-player (X & O) quick play
- 🔄 Real-time turn indicator
- 🏅 Smart winner / draw detection
- 📱 Responsive, modern gameboard design
- 🆕 “New Game” & “Reset” buttons for smooth replay
- 💻 Clean code — perfect to learn and customize

## 💡 How to Play

- Click any empty box to make your move.  
- Players alternate (⭕ and ❌).
- The game checks for a win or draw instantly.
- 🎉 Winner or draw message pops up!
- 🔄 Hit “Reset” or “New Game” to play again. Repeat the fun!
